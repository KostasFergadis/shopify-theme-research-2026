# AI Development & Tooling Usage

To ensure complete transparency and adherence to modern development standards, the following AI-assisted tools and engineering patterns were utilized during the research and documentation phase of this project:

## Tools Used

* **AI Code Assistant / LLM:** Utilized primarily for structuring the research documentation, formatting Markdown comparison tables (like the performance matrix in `RESEARCH.md`), and generating concise, standardized Git commit messages.

## Shopify Agent Skills

* **shopify-liquid:** This agent skill (sourced from the official [Shopify/agent-skills repository](https://github.com/Shopify/agent-skills/tree/main/shopify-liquid)) was referenced conceptually to ensure architectural compatibility with Online Store 2.0 component guidelines.
* *Scope Note:* No custom Liquid code generation was performed by AI; usage was strictly limited to reviewing architecture standards, theme evaluation, and structural validation.

## Security Notice

In strict accordance with the project brief and security best practices:

* No personal prompts were included in the final repository.
* No API keys, development store credentials, or sensitive secrets were processed, shared, or stored during the AI assistance phase.
